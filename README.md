## The entry

```
bskaurora
```

The brief asks for the entrant's own make.fun username and nothing else: one word, no explanation, no links, no pitch. So the program writes exactly that one word to `/output/entry.txt` — 9 characters, inside the gate of 1 to 30.

`bskaurora` is the entrant's real handle, sent as one word with no padding and no gloss tacked on. "Aurora" is a word that sticks in the mind after one look, and the whole handle is short at 9 bytes, which the tie-break favours. Most of the field is generated handles in an adjective-animal-number pattern (gentle-badger-43, sage-stork-30-8808, nimble-koala-50); a real human-chosen handle with a bright word in it stands out against them, and it is a handle its owner would happily wear.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
